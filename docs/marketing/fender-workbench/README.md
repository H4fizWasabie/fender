# Fender Workbench Visual Archive

Source material from the D51 UI/UX redesign, retained for future marketing, launch notes, and behind-the-scenes design storytelling.

## Directories

- `directions/` — five deliberately unfinished visual-world sketches. `engineers-job-docket.png` is the selected direction; the others are rejected alternatives or the conventional baseline.
- `compositions/` — three high-fidelity layout studies. `centered-docket-approved.png` is the user-approved north star.
- `renders/` — desktop and mobile captures across implementation passes. Files ending in `-final.png` are the accepted fresh-session UI.

## Usage guidance

- Direction and composition images are synthetic design studies. They include demonstration content and must not be presented as screenshots, benchmarks, customer work, or proof of implemented capabilities.
- The approved composition is a north star, not a literal product screenshot. Its example repository, task, file count, checks, certificate, and logo mark were intentionally not copied into Fender.
- Final renders show the real embedded workbench in a fresh-session state using live runtime metadata. They do not demonstrate a completed task or claim external verification.
- Preserve original aspect ratios. Crop copies for campaigns; keep these files unchanged as the source archive.
