# Fender — Memory / ICM Layers Design (Ticket 05)

**Date:** 2026-08-04
**Status:** Draft — pending user review
**Supersedes:** spec §3.6 placeholder. D14/D17/D28 are the design; this spec is the Fender implementation.

ICM memory architecture: layered files that record what's in the codebase (navigation), not just context strategy. Convention files load DIRECTLY (canonical sources — never copied into PROJECT.md). PROJECT.md always loaded; MAP.md is the navigation front door (generated by code-intel, ticket 07); reference/ + working/ selective.

---

## 1. Scope

Build `internal/memory`: the ICM memory workspace + bootstrap layer.

1. **`.fender/` workspace structure** — `Ensure()` creates it on first run:
   ```
   .fender/
     memory/
       PROJECT.md        # Layer 0 — always loaded. Seeded by Ensure (template), maintained via edit tools.
       MAP.md            # Layer 1 — navigation. Schema defined here; generation by code-intel (ticket 07).
       reference/        # Layer 2 — selective loading via read/search tools (convention only, no machinery).
       working/          # Layer 4 — durable deliberate notes (ticket 04 explicitly deferred this here).
     skills/             # Layer 3 — ticket 06's job; Ensure creates the empty dir as a seam.
   ```
2. **Convention-file detection** (bootstrap, from the 2026-08-04 discussion): AGENTS.md / CLAUDE.md / CONTEXT.md, loaded DIRECTLY, layered precedence:
   - user-level `~/.fender/AGENTS.md` (global rules, loaded first)
   - project root `AGENTS.md` — fallback `CLAUDE.md` if no AGENTS.md
   - project root `CONTEXT.md` (ICM Layer 1) if present
   - Nested directory `AGENTS.md` (directory-scoped): detection function is dir-aware (seam); v1 loads root level only.
   - `README.md` / `CONTRIBUTING.md` / `.cursorrules` are NEVER auto-loaded (on-demand via tools only).
3. **System prompt assembly** — `Bootstrap.System()` composes the always-loaded layer: convention files (in precedence order) + PROJECT.md. Order: user AGENTS.md → project AGENTS.md/CLAUDE.md → CONTEXT.md → PROJECT.md (later = more specific).
4. **Working memory** — `.fender/memory/working/*.md` + `patterns.md`. Notes pruned by age (7 days, mino `working_memory.md` rule); patterns persist. The agent writes notes via the existing file tools — no new note tool (ponytail: write_file exists).
5. **Agent wiring** — nil-safe `Mem *memory.Memory` on Agent (ticket-03 pattern); bootstrap runs at Run start; memory system content prepends the agent's System.

## 3. Decisions

| # | Decision |
|---|----------|
| 1 | **Convention files load directly, always.** AGENTS.md (user → project → nested-seam), CLAUDE.md fallback, CONTEXT.md. Canonical sources: nothing copied into PROJECT.md; PROJECT.md only holds what humans/agents wrote there directly. |
| 2 | **Never auto-load README/CONTRIBUTING/.cursorrules** — on-demand via tools. |
| 3 | **MAP.md v1 = hand-maintainable schema + code-intel seam.** Schema: frontmatter (`# MAP.md — generated by code-intel` marker, optional `updated:` timestamp) + one `## <area>` section per module with a one-line description + key files list. v1: `Ensure()` writes a placeholder ("MAP.md not generated yet — code-intel ticket 07"); agents may maintain it by hand via edit tools. Ticket 07 replaces the body, never the schema. |
| 4 | **Working notes: 7-day prune, patterns persist.** `working/*.md` removed when mtime > 7 days at bootstrap; `patterns.md` never pruned. |
| 5 | **Bootstrap is idempotent and quiet.** `Ensure()` never errors on existing content, never overwrites user edits. |
| 6 | **Memory is optional at the agent level** — `Mem == nil` = current behavior, all existing tests untouched (ticket-03/ticket-04 pattern). |

## 4. Module API — `internal/memory`

```go
package memory

const (
    NotesMaxAge = 7 * 24 * time.Hour
)

type Memory struct {
    root string // project root — .fender/ lives under it
}

func New(root string) *Memory

// Ensure creates .fender/{memory/{PROJECT.md,MAP.md,reference/,working/},skills/}
// if missing. PROJECT.md/MAP.md seeded with templates when absent. Idempotent.
func (m *Memory) Ensure() error

type ConventionFile struct {
    Path    string // absolute
    Kind    string // "AGENTS.md" | "CLAUDE.md" | "CONTEXT.md"
    Layer   string // "user" | "project"
}

// Detect finds convention files. dir-aware (nested seam): v1 calls with root.
// Order: user ~/.fender/AGENTS.md, project AGENTS.md (or CLAUDE.md fallback), CONTEXT.md.
func (m *Memory) Detect(dir string) []ConventionFile

// Bootstrap = Ensure + Detect + prune stale working notes.
func (m *Memory) Bootstrap() (*Bootstrap, error)

type Bootstrap struct {
    Convention []ConventionFile
    ProjectMD  string // PROJECT.md content, "" if absent
    MAPMD      string // MAP.md content, "" if absent (not always-loaded — navigation is on-demand)
}

// System composes the always-loaded layer: convention contents (in order) + PROJECT.md.
func (b *Bootstrap) System() string

// Working returns the pruned catalog of working/ files: "label: path (age)".
// Pruning happens in Bootstrap; catalog is informational (agents fetch via read_file).
func (m *Memory) Working() []string
```

Notes:
- `Memory` is a struct, not an interface (ponytail rule — one implementation).
- `Detect` reads files as UTF-8; unreadable files are skipped with a warning (never a hard error — a broken convention file must not kill the session).
- System assembly caps total memory content at 8K chars (the always-loaded layer stays small — prevention over compression, D14); excess is truncated oldest-first with a marker. The 8K ceiling is below ticket 04's InlineLimit so memory never triggers artifact compaction by itself.

## 5. Agent loop wiring (`internal/agent`)

- `Agent` gains `Mem *memory.Memory` — nil-safe.
- `Run` start: `if a.Mem != nil { b, err := a.Mem.Bootstrap(); if err == nil { a.System = b.System() + a.System } }` — memory content prepends the agent's own system prompt (constitution first, then task-specific).
- Delegate children inherit the same `Mem` (shared project memory is correct — subagents work the same codebase; only the *artifact* context is isolated per D38).
- `fender init` (ticket 08) wraps `Ensure()`.

## 6. Test strategy

| Test | Technique |
|------|-----------|
| Ensure creates full structure; second call is a no-op (idempotent) | workspace scaffold |
| Detect finds project AGENTS.md; prefers AGENTS.md over CLAUDE.md; finds CONTEXT.md; finds user-level ~/.fender/AGENTS.md (HOME overridden) | detection + precedence |
| Detect skips missing files, README.md never detected | negative detection |
| Unreadable convention file → skipped, no error | resilience |
| System() order: user → project → CONTEXT.md → PROJECT.md; PROJECT.md content never duplicated from convention | assembly + canonical sources |
| System() cap: >8K memory content truncated with marker, never exceeds ceiling | prevention |
| Working prune: stale (mtime > 7d) removed, fresh kept, patterns.md never removed | prune |
| Agent end-to-end: Mem set → system prompt contains convention content; Mem nil → unchanged behavior | integration, nil-safety |

## 7. Acceptance criteria

1. `go test ./...` green, `go vet ./...` clean, single binary builds.
2. All ticket-03/ticket-04 tests pass unchanged (nil-safe Mem).
3. Convention files are read directly — no file in `.fender/` ever contains copied convention content (test-enforced: PROJECT.md template ≠ AGENTS.md content).
4. Bootstrap runs at Run start; a session in a fresh directory works without any setup (Ensure auto-creates).
5. `CHANGELOG.md` updated on every commit (hook-enforced).
6. Wayfinder ticket 05 resolved; frontier → 06 (Skills).
